I wanted to make a nextbot style game so I made this
I built it on godot and drew the sprites in libresprite

In the game you can:

*You can move with WASD
*You can sprint with shift
*You can jump with space
*You can shoot your gun to protect yourself from the monster

In the game there is a monster that stalks and attacks you and if it reaches you, the game ends
You also have a stamina and it gets drained when you run by pressing shift


How to install:
You can install by downloading it from this link: https://github.com/omrekinci/Forest/releases/tag/SelectTag
